Statuses

QualifiedPasses all five criteria → HubSpot deal, handoff email, Telegram
Needs reviewBorderline, never auto-declined → Review queue; founder decides
Not a fitOutside Pune/PCMC · advice/decor only · restaurant/retail/gym · <6 weeks · budget clearly too low
EscalationExisting-client complaint → URGENT email + Telegram, never a deal
IncompleteArea or property type missing → Review queue
MissedMissed or dropped call → dashboard only

Guardrails

  • No price figures, ever — pricing.md's exact deflection; every agent line scanned
  • Code decides the status; AI only reads and summarises
  • Never auto-decline a borderline case
  • No false success — sent only on a 2xx; each channel logged
  • Secrets only in env vars; machine routes need secrets
